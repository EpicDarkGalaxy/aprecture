# Current State
- As of right now, it supports the F-Droid and IzzyOnDroid providers.
- The next planned provider is APK Mirror.
- It can display app details such as Name, Version, Developer Name, and other information.
- It can show app screenshots.
- It can install apps.
- It can show the appropriate install button based on the app's state. For example, if the app is already installed, it shows an Open button.
- It has three main screens: Apps, Search, and Settings.
- Settings currently has only three options: Clear Cache, Refresh Index, and Opt-in Sources.

# Opt-in Sources?
Not every provider can be trusted. Opt-in Sources are exactly those. This includes providers such as APK Mirror, Uptodown, and all the :skull: mod APK providers.
The Opt-in Sources setting allows users to enable and disable these providers.
