# Current State
- As of right now, it supports F-Droid and IzzOnDroid providers,
Next planned provider is Apk-Mirror.
- Can show app details such as **Name**, **Version**, **Developer Name** and others.
- Can show app screenshots.
- Can Install the app.
- Can show install button according to app's state (Example: if the app is already installed, show Open button)
- Has 3 Main Screen (Apps, Search and Settings)
- Settings right now has only 3 Options (Clear Cache, Refresh Index and Opt-in Sources)

# Opt-in Sources?
Not every provider can be trusted, **Opt-in Sources** are exactly those.  
that includes providers such as **Apk-Mirror**, **Uptodown** and all the :skull: **Mod Apk** providers.  
The **Opt-in Sources** setting allows users to **Enable** and **Disable** those providers.
